Concept & Definition

The Average (Arithmetic Mean) represents the central value that equally balances a set of numbers.

Fundamental Relationship:
• Average = (Sum of Observations) / (Number of Observations)
• Sum = Average × Number of Observations
• Net Deviation Property: The algebraic sum of deviations of all elements from their average is always 0.
📐

Core Average Formulas

⚖️ Weighted Average
x̄_w = (n₁A₁ + n₂A₂) / (n₁ + n₂)
When combining two groups with sizes n₁, n₂ and averages A₁, A₂.
🚗 Average Speed (Equal Distances)
Avg Speed = (2xy) / (x + y)
For equal distance traveled at speed x and returned at speed y.
🔢 Average of AP Series
Avg = (First Term + Last Term) / 2
For any consecutive numbers or arithmetic progression.
🔄 Inclusion / Replacement Formula
New = Old Avg + (Total Persons × Diff)
Replaced Value = Excluded Value ± (N × Increase/Decrease).

Step-by-Step Solved Examples

Ex 1 The average weight of 24 students is 40 kg. If the teacher's weight is included, the average increases by 1 kg. Find the teacher's weight.
Given Initial Students = 24, Initial Avg = 40 kg, New Count = 25, Change = +1 kg
Deviation Method Weight of New Member = New Average + (Initial Count × Increase in Avg)
Solution Weight = 41 + (24 × 1) = 41 + 24 = 65 kg
Old Avg Base 40 kg
+
Added for 25 Persons 25 × 1 = 25 kg
=
Teacher's Weight 65 kg
✓ Final Answer: 65 kg
Ex 2 A person travels from City A to City B at 60 km/h and returns at 40 km/h. What is his average speed for the whole journey?
Given x = 60 km/h, y = 40 km/h (Distances are identical)
Formula Average Speed = (2xy) / (x + y) = (Total Distance) / (Total Time)
Solution (2 × 60 × 40) / (60 + 40) = 4800 / 100 = 48 km/h
✓ Final Answer: 48 km/h
Ex 3 The average score of 50 innings of a batsman is 45. Find the sum of all runs scored. If in the next inning he scores 106, find his new average.
Given Innings (N₁) = 50, Old Avg = 45 → Total Runs = 50 × 45 = 2,250
Calculation New Total = 2250 + 106 = 2356 → New Innings = 51
Solution New Average = 2356 / 51 = 46.2 runs
✓ Final Answer: 46.2 runs

Speed-Solving Tips & Shortcuts

⚡
Arithmetic Operations on Series: If every term in a set is increased, decreased, multiplied, or divided by k, the average also changes by the same operation k.
🎯
First n Natural Numbers: Average of first n natural numbers is (n + 1) / 2. Average of first n even numbers is n + 1. Average of first n odd numbers is n.
🔄
Correcting Wrong Data: Correct Avg = Old Avg + [(Correct Entry − Wrong Entry) / Total Items].
🏎️
3 Equal Distance Speeds: Avg Speed = (3xyz) / (xy + yz + zx) for speeds x, y, and z covering equal segments.
⚠️

Common Mistakes to Avoid

🚫
Mistake 1: Taking Direct Arithmetic Mean of Speeds
Never average speeds directly as (x + y) / 2 for equal distances. Time spent at the lower speed is longer, requiring the harmonic mean 2xy / (x + y).
🚫
Mistake 2: Forgetting to Update Total Count (N)
When a new person joins a group of 20, the new divisor is 21; when calculating replacements, the total count remains 20.
🚫
Mistake 3: Equal Weighting in Combined Groups
If Class A (30 students) averages 80 marks and Class B (20 students) averages 60 marks, the overall average is not 70; it is (30×80 + 20×60) / 50 = 72.
