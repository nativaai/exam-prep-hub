Algebraic Foundations & Quadratic Roots

For a standard quadratic equation ax² + bx + c = 0 (where a ≠ 0), the roots α and β are determined by the quadratic formula:

Roots & Discriminant Properties:
• Sum of Roots: α + β = −b / a
• Product of Roots: αβ = c / a
• Discriminant D = b² − 4ac (D > 0: Real & Distinct; D = 0: Real & Equal; D < 0: Complex/Imaginary).

Core Reciprocal & Polynomial Identities

🔹 If x + 1/x = k
x² + 1/x² = k² − 2
x³ + 1/x³ = k³ − 3k
📈 If x − 1/x = k
x² + 1/x² = k² + 2
x³ − 1/x³ = k³ + 3k
⚡ 3-Variable Cube Identity
a³ + b³ + c³ − 3abc = (a+b+c)(a²+b²+c²−ab−bc−ca)
Also = ½(a+b+c)[(a−b)² + (b−c)² + (c−a)²].
🎯 4th Power Reciprocal
x⁴ + 1/x⁴ = (k² − 2)² − 2
Derived by squaring (x² + 1/x²) consecutively.

Step-by-Step Solved Examples

Ex 1 If x + 1/x = 4, find the value of (i) x² + 1/x² and (ii) x³ + 1/x³.
Given x + 1/x = k = 4
Square Formula x² + 1/x² = k² − 2 = 4² − 2 = 16 − 2 = 14
Cube Formula x³ + 1/x³ = k³ − 3k = 4³ − 3(4) = 64 − 12 = 52
✓ Final Answer: x² + 1/x² = 14, x³ + 1/x³ = 52
Ex 2 If a + b + c = 0, evaluate (a² / bc) + (b² / ca) + (c² / ab).
Given a + b + c = 0
Simplification Common Denominator: (a³ + b³ + c³) / abc
Property When a + b + c = 0, a³ + b³ + c³ = 3abc → (3abc) / abc = 3
✓ Final Answer: 3
Ex 3 Find the roots of the quadratic equation 2x² − 7x + 3 = 0.
Given a = 2, b = −7, c = 3 (Product = 6, Sum = −7)
Factorization 2x² − 6x − x + 3 = 0 → 2x(x − 3) − 1(x − 3) = 0 → (2x − 1)(x − 3) = 0
Roots 2x − 1 = 0 → x = ½  |  x − 3 = 0 → x = 3
✓ Final Answer: x = 3, ½

Speed-Solving Tips & Shortcuts

✨
Value Putting Strategy: In symmetric identities with multiple variables, substitute simple trial values like a = 1, b = 1, c = 1 (ensuring denominator ≠ 0).
⚡
Special Reciprocal Form: If x + 1/x = 2, then strictly x = 1. If x + 1/x = −2, then strictly x = −1.
🔄
Degree Counting Method: Match the algebraic degree of homogeneous polynomial questions directly with options to discard invalid choices.
🎯
Sign Rule of Roots: For ax² + bx + c = 0:
• (+, +) → Both roots negative (−, −)
• (−, +) → Both roots positive (+, +)
⚠️

Common Mistakes to Avoid

🚫
Mistake 1: Forgetting Signs in (x − 1/x) Cubing
For (x − 1/x) = k, the cube is k³ + 3k, not k³ − 3k. Add 3k when working with negative signs.
🚫
Mistake 2: Canceling Variables Across Equations
Dividing both sides by a variable (e.g., dividing x² = 4x by x) loses the valid root x = 0. Always factorize: x(x − 4) = 0.
🚫
Mistake 3: Zero-Denominator Substitution
When testing values, never assign numbers that cause division by zero in the expression (e.g., setting a = b when terms contain 1/(a − b)).
