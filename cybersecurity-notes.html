The CIA Triad & Threat Framework

Cybersecurity is the practice of protecting systems, networks, devices, and data from digital attacks, unauthorized access, or damage.

The CIA Triad Pillars:
• Confidentiality: Preventing unauthorized access to sensitive information (e.g. Encryption, Access Controls).
• Integrity: Safeguarding accuracy and preventing unauthorized tampering of data (e.g. Hashing, Digital Signatures).
• Availability: Ensuring timely, reliable access to systems for authorized users (e.g. Redundancy, DDoS Mitigation).
📐

Core Cyber Threat & Defense Domains

🦠 Malware Taxonomy
Virus | Worm | Trojan | Ransomware
Virus requires a host file. Worm self-replicates independently over networks. Trojan disguises as legitimate software. Ransomware encrypts files for money.
🎣 Social Engineering & Attacks
Phishing | Spoofing | MITM | DDoS
Phishing uses fake emails/websites to steal credentials. DDoS floods servers with traffic to cause downtime. MITM intercepts live data.
🔑 Cryptography & Key Systems
Symmetric (1 Key) vs Asymmetric (2 Keys)
Symmetric (AES/DES) uses same secret key. Asymmetric (RSA) uses Public Key (Encrypt) + Private Key (Decrypt). Hash (SHA-256) is 1-way.
🛡️ Security Defenses & Laws
Firewall | VPN | 2FA | IT Act 2000
Firewall filters packets based on rules. 2FA requires two distinct factors (Password + OTP). IT Act 2000 governs cybercrimes in India.

Step-by-Step Solved Examples

Ex 1 A malicious program self-replicates across a corporate network without attaching itself to any existing file or requiring human execution. What type of malware is it?
Options: (A) Computer Virus  |  (B) Worm  |  (C) Trojan Horse  |  (D) Spyware
Malware Characteristics • Virus: Attaches to an executable host file and runs when opened by a user.
• Trojan Horse: Appears as useful software but contains hidden malicious code.
• Worm: Standalone program that self-replicates autonomously across network vulnerabilities.
Solution Self-replicating network malware is a Worm (Option B).
✓ Final Answer: Worm
Ex 2 In Public Key Cryptography (Asymmetric Encryption), if User A wants to send an encrypted private message to User B, which key should User A use to ENCRYPT the message?
Options: (A) User A's Private Key  |  (B) User A's Public Key  |  (C) User B's Public Key  |  (D) User B's Private Key
Asymmetric Encryption Principle • Public Key: Distributed freely to everyone; used by anyone to Encrypt messages intended for the key owner.
• Private Key: Kept strictly secret by the owner; used exclusively to Decrypt messages.
Solution User A encrypts using User B's Public Key (Option C) so that only User B can decrypt it with User B's Private Key.
✓ Final Answer: User B's Public Key

Common Mistakes to Avoid

🚫
Mistake 1: Confusing Computer Virus and Computer Worm
A Virus requires human interaction and a host file to execute and spread. A Worm is a standalone program that self-propagates across network vulnerabilities without human intervention.
🚫
Mistake 2: Mixing Up Symmetric and Asymmetric Encryption Keys
Symmetric Encryption (AES, DES) uses a single shared secret key for both encryption and decryption. Asymmetric Encryption (RSA, ECC) uses a key pair (Public key to encrypt, Private key to decrypt).
🚫
Mistake 3: Reversing Hashing and Encryption
Encryption is a 2-way process (can be decrypted back to plaintext with a key). Hashing (MD5, SHA-256) is a 1-way mathematical function designed to generate a fixed-length string for integrity checks; it cannot be reversed.
