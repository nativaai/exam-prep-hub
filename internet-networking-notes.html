Network Architecture & Reference Models

A Computer Network connects autonomous computing nodes to share hardware, files, and services over physical or wireless transmission media.

Geographical Network Types:
• PAN: Personal Area Network (Bluetooth, range ~10m).
• LAN: Local Area Network (Office / Home, Ethernet / Wi-Fi).
• MAN: Metropolitan Area Network (City-wide cable network).
• WAN: Wide Area Network (Global coverage, e.g. The Internet).
📐

Core Networking Domains

🌐 OSI 7-Layer Architecture
App > Pres > Sess > Trans > Net > DL > Phys
Layer 7: Application | L6: Presentation (Encryption/Compression) | L5: Session | L4: Transport (TCP/UDP) | L3: Network (IP/Router) | L2: Data Link (MAC/Switch) | L1: Physical (Bits/Hub).
🔢 IP Addressing (IPv4 vs IPv6)
IPv4: 32-bit | IPv6: 128-bit
IPv4 has 4 octets separated by dots (e.g. 192.168.1.1). IPv6 uses 8 hexadecimal blocks separated by colons (e.g. 2001:db8::1).
🔧 Network Devices & Operating Layer
Hub (L1) | Switch (L2) | Router (L3)
Hub broadcasts to all ports. Switch filters by 48-bit MAC Address. Router routes packets across networks using IP addresses. Gateway converts protocols.
🔌 Key Application Protocols & Ports
HTTP (80) | HTTPS (443) | DNS (53)
FTP (20/21, Files), SSH (22, Secure Shell), SMTP (25, Sending Email), POP3 (110, Fetching Email), DHCP (67/68, Auto IP assignment).

Step-by-Step Solved Examples

Ex 1 Which layer of the OSI reference model is responsible for end-to-end process transmission, segmenting data, flow control, and error correction?
Options: (A) Network Layer  |  (B) Transport Layer  |  (C) Data Link Layer  |  (D) Presentation Layer
Layer Responsibilities • Network Layer (L3): Routing packets using IP addresses.
• Data Link Layer (L2): Framing data into frames using MAC addresses.
• Transport Layer (L4): End-to-end process communication, segmentation, port addressing, flow control (TCP/UDP).
Solution Correct layer is the Transport Layer (Option B).
✓ Final Answer: Transport Layer
Ex 2 Match the Network Topology with its defining structural characteristic:
1. Star Topology  |  2. Bus Topology  |  3. Mesh Topology  |  4. Ring Topology
Topology Definitions • Star: All devices connect to a central hub/switch; single point of failure at hub.
• Bus: Single central coaxial cable (backbone) with terminators at both ends.
• Mesh: Every node has a dedicated point-to-point link to every other node ($N(N-1)/2$ links) → Maximum fault tolerance.
• Ring: Data circulates unidirectionally in a closed loop via token passing.

Speed-Solving Mnemonics & Shortcuts

🧠
OSI Layers Mnemonic (Top to Bottom):
All People Seem To Need Data Processing
(Application → Presentation → Session → Transport → Network → Data Link → Physical).
⚡
TCP vs UDP Protocol Rule:
• TCP: Connection-oriented, 3-way handshake (SYN, SYN-ACK, ACK), reliable, error-checking (Web, Email).
• UDP: Connectionless, unreliable, fast, low overhead (Video streaming, Gaming, DNS).
🏷️
MAC Address Format: 48-bit (6 Bytes) physical/hardware address burned into the NIC by manufacturer, formatted in hexadecimal (e.g. 00:1A:2B:3C:4D:5E).
🔍
URL Breakdown:
In https://www.example.com/index.html:
• https:// = Protocol
• www.example.com = Domain Name (Host)
• /index.html = Resource Path

Common Mistakes to Avoid

🚫
Mistake 1: Confusing Hubs, Switches, and Routers
A Hub is a Layer 1 device that blindly broadcasts incoming signals to all ports. A Switch is a Layer 2 intelligent device that sends data only to the target MAC address. A Router is a Layer 3 device that routes data between different IP networks.
🚫
Mistake 2: Mixing Up IPv4 and IPv6 Bit Lengths
IPv4 uses 32 bits (4 octets, decimal, e.g. 192.168.0.1), allowing ~$4.3$ billion unique addresses. IPv6 uses 128 bits (8 hex groups, e.g. fe80::1), providing $2^{128}$ addresses.
🚫
Mistake 3: Confusing HTTP and HTTPS Ports
Standard unencrypted HTTP operates on Port 80. Encrypted HTTPS (which uses SSL/TLS) operates on Port 443.
