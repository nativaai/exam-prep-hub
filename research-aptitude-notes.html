Research Paradigms & Epistemology

Research is a systematic, controlled, empirical, and critical investigation of hypothetical propositions about presumed relations among natural phenomena.

Positivism vs Post-Positivism:
• Positivism (Auguste Comte): Quantitative, objective reality, deductive logic, empirical observation, deterministic.
• Post-Positivism (Karl Popper): Qualitative/mixed, subjective reality, multiple perspectives, inductive/falsificationist, probabilistic.
📐

Core Research Types & Classifications

🧪 Fundamental vs Applied
Theory Creation vs Problem Solving
Fundamental (Pure): Adds to the existing pool of scientific knowledge and formulates theory. Applied: Solves immediate practical societal or industrial problems.
🔄 Action Research
Plan → Act → Observe → Reflect (PAOR)
Propounded by Kurt Lewin. Focuses on immediate localized intervention to improve classroom or organizational practices in a cyclical spiral.
⚖️ Experimental Research
Manipulate IV → Observe DV
Establishes cause-and-effect relationships. Researcher directly manipulates the Independent Variable (IV) while controlling extraneous variables to measure impact on the Dependent Variable (DV).
⏳ Ex-Post Facto Research
After-the-fact Investigation
Conducted when the independent variable has already occurred naturally (e.g. earthquake impact, dropout rates). IV cannot be manipulated or assigned randomly.
🎯

Sampling Techniques & Hypothesis Formulation

🎲 Probability Sampling
Simple | Stratified | Cluster | Systematic
Every population unit has a known, non-zero chance of selection. Minimizes researcher bias and allows broad generalizability of findings.
🎯 Non-Probability Sampling
Purposive | Quota | Snowball | Convenience
Selection based on subjective judgment. Snowball: Ideal for hidden or difficult-to-reach populations (e.g. rare disease patients) via peer referrals.
📊 Null vs Alternative Hypothesis
H₀ (No Difference) vs H₁ (Difference)
Null Hypothesis ($H_0$): Claims no significant difference/relationship. Alternative ($H_1$): Claims a significant effect exists. Statistical tests test $H_0$ directly.
⚠️ Type I and Type II Errors
Type I: Reject True $H_0$ | Type II: Retain False $H_0$
Type I Error ($\alpha$): False Positive (Rejecting a null hypothesis that is actually true). Type II Error ($\beta$): False Negative (Failing to reject a false null hypothesis).

Step-by-Step Solved UGC NET Examples

Ex 1 A researcher wants to study the lifestyle and challenges faced by a marginalized, secretive tribal group where individuals are difficult to trace directly. Which sampling method is most appropriate?
Options: (A) Stratified Random Sampling  |  (B) Snowball Sampling  |  (C) Systematic Sampling  |  (D) Cluster Sampling
Analysis Target group is hard-to-reach, secretive, and lacks an accessible sampling frame.
Method Rule Snowball (Chain-referral) sampling asks initial participants to identify and recruit further eligible subjects.
Solution The most suitable method is Snowball Sampling (Option B).
✓ Final Answer: Snowball Sampling
Ex 2 When a researcher rejects the Null Hypothesis ($H_0$) despite it being completely true in reality, which statistical error has been committed?
Options: (A) Type I Error  |  (B) Type II Error  |  (C) Sampling Bias  |  (D) Standard Error
Definition • Type I Error (α): Rejecting H₀ when H₀ is true (False Alarm).
• Type II Error (β): Accepting/retaining H₀ when H₀ is false.
Solution Rejecting a true null hypothesis is a Type I Error (Option A).
✓ Final Answer: Type I Error

Speed-Solving Mnemonics & Key Tips

🔄
Action Research Cycle Mnemonic:
Remember PAOR:
Plan → Act → Observe → Reflect.
🎲
Probability vs Non-Probability:
If it has "Random", "Stratified", "Cluster", or "Systematic", it is Probability. If it has "Quota", "Purposive", "Snowball", or "Convenience", it is Non-Probability.
📜
Thesis Citation Formats:
• APA (American Psychological Assoc.): Author, Year in text (e.g. Smith, 2024).
• MLA (Modern Language Assoc.): Author, Page (e.g. Smith 45).
⚖️
Research Ethics Vulnerability:
Ethics are most critically tested during: (1) Data Collection, (2) Data Analysis/Reporting, and (3) Plagiarism prevention in reporting.
⚠️

Common Mistakes to Avoid

🚫
Mistake 1: Confusing Stratified Sampling and Cluster Sampling
In Stratified Sampling, the population is divided into strata, and samples are randomly drawn from every stratum. In Cluster Sampling, the population is divided into natural groups (clusters), and entire clusters are chosen randomly.
🚫
Mistake 2: Mixing Ex-Post Facto with Experimental Design
In Experimental Research, the independent variable is actively manipulated by the researcher. In Ex-Post Facto, the event/cause has already occurred, so direct manipulation is impossible.
🚫
Mistake 3: Inverting Type I and Type II Errors
Remember: Type I = False Positive (rejecting truth; seeing an effect that isn't there). Type II = False Negative (accepting falsehood; missing a real effect).
