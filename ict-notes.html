Computer Memory Hierarchy & Storage Units

Computer memory follows a trade-off: Faster memory is smaller and more expensive per bit, while slower storage is larger and cheaper.

Hierarchy (Fastest & Smallest → Slowest & Largest):
1. CPU Registers (Fastest, volatile)
2. Cache Memory (SRAM - Level 1, 2, 3)
3. Main Memory (RAM) (DRAM - Volatile primary)
4. Solid State Drive (SSD) / Flash (Non-volatile secondary)
5. Hard Disk Drive (HDD) / Optical (CD/DVD/Blu-ray)
6. Magnetic Tape (Slowest, archival backup)

Data Storage Units & Number Conversions

💾 Storage Units Sequence
Bit → Byte → KB → MB → GB → TB → PB → EB
1 Byte = 8 Bits = 2 Nibbles (1 Nibble = 4 Bits). 1 KB = 1024 Bytes ($2^{10}$), 1 MB = $2^{20}$ Bytes, 1 GB = $2^{30}$ Bytes, 1 TB = $2^{40}$ Bytes.
🔄 Decimal to Binary
Successive Division by 2
Divide number by 2 repeatedly and record remainders from bottom to top (LSB to MSB). E.g., $(25)_{10} = (11001)_2$.
🔡 Hexadecimal Base-16
0–9 and A(10), B(11), C(12), D(13), E(14), F(15)
Convert 4-bit binary chunks into 1 Hex digit. E.g., $(1111)_2 = (\text{F})_{16}$, $(1010)_2 = (\text{A})_{16}$. Hexadecimal is used in IPv6 and MAC addresses.
🔋 RAM vs ROM
Volatile (RAM) vs Non-Volatile (ROM)
RAM: Loses data when powered off (Read/Write). ROM: Retains BIOS / firmware bootstrap instructions permanently.

Internet Protocols, Web & Cyber Threats

🌐 Core Internet Protocols
HTTP/S | FTP | SMTP | POP3 | IMAP | DNS
SMTP: Sends outgoing emails. POP3/IMAP: Retrieves incoming emails. DNS: Translates domain names into IP addresses.
🏷️ IPv4 vs IPv6 vs MAC Address
IPv4: 32-bit | IPv6: 128-bit | MAC: 48-bit
IPv4: 4 octets separated by dots (e.g. 192.168.1.1). IPv6: 8 hex blocks separated by colons. MAC: Physical hardware address on NIC.
🦠 Malware Classifications
Virus | Worm | Trojan | Ransomware | Spyware
Worm: Self-replicating across networks without host. Trojan: Disguised as legitimate software. Phishing: Fraudulent emails/links to steal credentials.
🏛️ National Digital Initiatives
SWAYAM | NDL | DigiLocker | ShodhGanga | SAMARTH
ShodhGanga: Repository of Indian PhD theses. ShodhGangotri: Synopsis repository. NDL: National Digital Library. DigiLocker: Cloud document wallet.

Step-by-Step Solved UGC NET Examples

Ex 1 What is the binary equivalent of the decimal number $(43)_{10}$?
Options: (A) 101011  |  (B) 101010  |  (C) 110101  |  (D) 100111
Successive Division by 2 43 ÷ 2 = 21 (rem 1) → 21 ÷ 2 = 10 (rem 1) → 10 ÷ 2 = 5 (rem 0) → 5 ÷ 2 = 2 (rem 1) → 2 ÷ 2 = 1 (rem 0) → 1 ÷ 2 = 0 (rem 1)
Read from Bottom to Top (MSB to LSB) Remainders: 1, 0, 1, 0, 1, 1
Verification $1\times 32 + 0\times 16 + 1\times 8 + 0\times 4 + 1\times 2 + 1\times 1 = 32 + 8 + 2 + 1 = 43$.
✓ Correct Answer: Option A (101011)₂
Ex 2 Arrange the following computer storage terms in ascending order of data capacity (Smallest to Largest):
1. Gigabyte  |  2. Terabyte  |  3. Megabyte  |  4. Petabyte  |  5. Kilobyte
Order Rule Kilobyte (KB) < Megabyte (MB) < Gigabyte (GB) < Terabyte (TB) < Petabyte (PB)
Sequence 5 (KB) → 3 (MB) → 1 (GB) → 2 (TB) → 4 (PB)
✓ Correct Order: KB → MB → GB → TB → PB

Common Mistakes to Avoid

🚫
Mistake 1: Confusing RAM with ROM Volatility
RAM is Volatile (erased when power is switched off). ROM is Non-Volatile (holds boot sequence and startup instructions permanently).
🚫
Mistake 2: Confusing Phishing with Pharming and Spoofing
Phishing uses deceptive emails/messages to steal login details. Pharming redirects web traffic to a fake bogus website by poisoning DNS servers.
🚫
Mistake 3: Mixing Bits and Bytes in File Transfer Calculations
Network speeds are stated in Mbps (Megabits per second, lowercase 'b'), while file sizes are in MB (MegaBytes, uppercase 'B'). 1 Byte = 8 Bits (8 Mbps = 1 MB/s).
